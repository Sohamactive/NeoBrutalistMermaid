# NeoBrutalistMermaid

A web-based Mermaid diagramming tool with a neo-brutalist interface.

## Features

- Live Mermaid editor + preview split layout
- Debounced rendering with syntax error fallback
- Mermaid config controls (theme, curve, node spacing, font)
- Neo-brutalist theme controls (primary color, dark/light mode, border thickness)
- Export as SVG and PNG
- Copy SVG and shareable URL
- Undo/redo history with localStorage persistence
- Layout presets (compact, presentation, fullscreen)

## Development

```bash
npm install
npm run dev
```
